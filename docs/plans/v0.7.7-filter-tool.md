# V0.7.7 Filter 工具实施方案

## 1. 需求与口径

| ID | 验收口径 |
|---|---|
| V0.7.7-01 | Tool 菜单和右侧工具区提供 Filter，子窗口可选 Mean、Gaussian、Median 及 3×3、5×5、7×7 kernel；Gaussian 可设置 sigma。 |
| V0.7.7-02 | 每次 Apply 捕获当前 `displaySource_`；Bayer Extract 或前一次 Filter 的结果可继续作为输入，原始文档和输入像素源保持只读。 |
| V0.7.7-03 | 超大 RAW 不生成完整滤波副本：显示预览最长边不超过 1024，准确像素按需计算并使用有界瓦片缓存。 |
| V0.7.7-04 | Mean/Gaussian 使用可分离卷积，Median 使用滑动窗口精确中位数；后台任务可取消，过期结果不得覆盖新文档。 |

边缘采用 clamp-to-edge。无效或非有限样本不参与权重或中位数；窗口中没有有效样本时输出无效。Median 的偶数有效样本取中间两值平均。

## 2. 管线设计

`MainWindow::beginFilter` 在 Apply 时保存当前显示 RAW 的共享只读引用。应用层 `FilterService` 只创建新的 `DecodedImage` 描述、最长边 1024 的信号预览及 `FilteredPixelSource`；不会修改 `DocumentSession::original()`，也不会创建 W×H 输出数组。

准确像素查询通过 64×64 输出瓦片完成。每块只读取一次带 kernel halo 的输入区域，然后缓存滤波结果。缓存最多保留 320 块，约 12 MiB，可覆盖目标 200 MP 图像常见的约 20K 像素宽扫描行，避免 Pixel Statistics 逐行访问时反复重算同一瓦片；超过该宽度时仍保持严格内存上限。

连续 Apply 形成不可变的惰性处理链：

```text
current display RAW
  -> bounded filtered preview
  -> lazy exact filtered pixel source
  -> next Filter / Pixel Info / Pixel Statistics
```

## 3. 算法性能

- Mean：两个一维均匀 kernel，复杂度由 O(W×H×K²) 降为 O(W×H×K)。
- Gaussian：预计算一维权重并做横向、纵向卷积，同样为 O(W×H×K)。
- Median：每行首个窗口建立双 multiset，向右移动时只删除旧列、加入新列，避免每个像素重新收集和排序 K² 个样本。
- Preview：优先复用已有信号预览，但仍会二次约束到最长边 1024；没有信号预览时直接按 1024 边界抽样源像素。
- 规则 Bayer Preview：抽样坐标保持 2×2 CFA phase 并在输出中记录该语义，使后续 Demosaic 可直接使用有界内存预览，不触发全图 Filter 瓦片。
- Exact source：64×64 瓦片带 halo 计算，LRU 有界复用；像素标注只触发可见瓦片，统计扫描可复用完整瓦片行。

## 4. 验证

- 5×5 线性网格验证 Mean/Gaussian 中心值和 clamp 边缘黄金值；3×3 脉冲验证 Median 去噪且输入不变。
- 连续 Mean → Median 验证第二次输入来自当前显示结果，元数据记录完整处理链。
- 128×64 两瓦片扫描精确读取 8,712 次，重复查询零新增读取；4096×2 跨 64 块的逐行扫描精确读取 16,896 次，证明不会按行重算。
- 1100 边信号预览输出限制为 1024；非法 kernel 和预取消返回结构化错误。
- 主窗口端到端先提取 10×10 的 2×2 左上位置为 5×5，再执行 3×3 Mean，输出 (0,0) 为 7.333…，证明 Filter 使用当前显示提取结果。
