# V0.7.13 全图直方图与 Display Window 设计

## 1. 需求映射

- 规则 Bayer RAW：全图单遍扫描并分别显示 R、Gr、Gb、B 四条曲线；
- RGB：全图单遍扫描并显示 R、G、B 与 Rec.709 Y 曲线；
- 无规则 Bayer 排列或单通道提取：显示一条灰度/信号曲线；
- Display BLV/WLV 输入保留一位小数，并与直方图横轴上的双手柄保持双向同步；
- 放大镜以点击时的 BLV/WLV 固定为横轴观察区间，供窄动态范围精调，再次点击恢复完整信号范围。

## 2. 数据口径与性能

`GlobalHistogramService` 读取当前 `displaySource` 的全分辨率只读 `IPixelSource`，不统计缩放预览，也不修改原始数据。任务运行于后台并支持 cancellation 与 generation 失效；新显示源不会被旧统计结果覆盖。

- UInt8/RGB 使用 256 bins；RAW 使用 65,536 bins，从而为常见 UInt16 保留逐码值分辨率；
- Bayer 四通道在一次 W×H 遍历中按实际像素通道分流，不重复扫描四遍；
- RGB 的 Y 使用 `0.2126R + 0.7152G + 0.0722B`；
- 绘制时把可见 bins 聚合到控件的屏幕列，曲线复杂度受控件宽度约束，而不是受 65,536 bins 约束；
- 纵轴统一使用 `log1p(count)`，保留通道间相对关系并降低尖峰对弱分布的遮蔽；
- BLV/WLV/Gamma 只改变显示窗口和标记，不重新扫描全图；只有当前显示源改变才重新计算。
- 完整 Grayscale16 RAW 不生成第二份整图：视口仅对当前屏幕可见矩形使用 65,536 项 Display LUT 映射并缓存，缩略导航使用同一 LUT 的有界采样，因此 BLV/WLV 会真实影响显示而不会复制 400 MB 级输入。

## 3. UI 与交互

直方图采用固定深色技术绘图区、细网格、半透明填充和高对比曲线：R 红、Gr 亮绿、Gb 青绿、B 蓝；RGB 模式为 R/G/B 加白色 Y；具有单一 Bayer 来源的提取结果沿用该通道颜色，无法确定来源的单通道为中性灰。顶部显示自动模式、通道图例及 `FULL IMAGE`/`WINDOW DETAIL` 状态。

BLV 蓝色手柄与 WLV 白色手柄共用直方图横轴，拖动过程实时更新右侧一位小数输入、RAW 视口和撤销状态；一次完整拖动合并为一个 Display 编辑步骤。键盘左右键调整当前手柄，Shift+左右键选择 WLV。

放大时横轴固定为点击瞬间的 BLV/WLV，避免拖动手柄后坐标系追随导致手柄无法控制。若 Undo/Redo 恢复到观察区间以外，观察区间自动扩展以包含恢复值。

## 4. 刷新范围

- 新打开、Extract、Filter、Demosaic、变换、Undo/Redo 切换显示源：取消旧统计并后台重算；
- BLV/WLV SpinBox、双手柄、Reset、Undo/Redo Display Mapping：同步数值、双手柄和显示渲染，不重算 histogram bins；
- RGB/RAW/单通道切换：自动更新模式、图例、数值范围和放大状态；
- Demosaic 在途任务仍会在 Display Mapping 变化时失效，避免旧映射 RGB 覆盖新窗口。

## 5. 验证

- 应用层黄金测试覆盖 Bayer 四通道、RGB+Y、单通道、bin 总数和预取消；
- UI 离屏验证 R/Gr/Gb/B 四种曲线颜色、共轴手柄拖动信号、窗口放大状态；
- 主窗口端到端验证自动 Bayer 模式、四曲线、BLV/WLV 一位小数、SpinBox/手柄同步和放大镜。
