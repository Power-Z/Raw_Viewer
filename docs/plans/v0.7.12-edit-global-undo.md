# V0.7.12 编辑功能与全局五步撤销方案

## 1. 需求

- 编辑菜单增加 Flip、Mirror、Rotate Left、Rotate Right、Rotate 180，并为每项提供快捷键；
- 将既有仅覆盖 Display BLV/WLV/Gamma 的五步撤销扩展为当前文档的全局编辑历史；
- 撤销/重做后同步刷新 RAW/RGB 显示、直方图、精确像素、状态栏、工具可用性和仍有效的 Pixel Statistics。

## 2. 操作审计与历史范围

| 操作 | 进入五步历史 | 说明 |
|---|---:|---|
| Display BLV / WLV / Gamma / Reset | 是 | 连续编辑合并为一个逻辑步骤；输入尚未失焦时也可直接撤销 |
| Flip / Mirror / Rotate Left / Right / 180 | 是 | 记录惰性坐标变换后的不可变显示源 |
| Bayer Extract / Show Original | 是 | 恢复显示源及对应提取上下文 |
| Filter Apply | 是 | 每次 Apply 为一个处理步骤 |
| Demosaic Apply / Restore Source | 是 | 同时保存 RGB 输出和可恢复 Bayer 输入 |
| 打开另一个文档 | 否 | 新文档创建独立历史，不能撤销为另一个文件 |
| 平移、缩放、滚动条、统计 ROI | 否 | 属于视图/分析状态；遵循架构 9.2，不占处理历史 |
| 主题、Pixel Info/Statistics 偏好 | 否 | 属于持久化偏好，不修改图像管线 |
| CSV 导出 | 否 | 外部只读输出，没有可恢复的文档状态变化 |

## 3. 全局文档状态

`DocumentSession` 的历史项由单一 Display Mapping 扩展为完整逻辑状态：

- 当前 `DisplayMapping`；
- 当前不可变 `displaySource`；
- Demosaic 的 `preDemosaicSource`；
- 当前 `BayerExtraction` 上下文。

Undo/Redo 只切换共享指针和参数并增加 revision，不保存整图副本。历史仍严格限制为五个逻辑步骤；任何新编辑都会清空 Redo 分支。活动中的显示参数编辑可以直接回到编辑前值，并形成可 Redo 的一步。

后台管线结果到达时若 Display 参数仍在编辑，先将 Display 编辑封存为一步，再将管线结果记录为下一步，避免丢结果或把两类操作错误合并。Demosaic 依赖任务启动时的 Display Mapping，因此映射变化会立即使在途 Demosaic 失效。

## 4. 几何变换与性能

| 菜单项 | 快捷键 | 输出到输入坐标 |
|---|---|---|
| Flip | `Ctrl+Alt+V` | `(x, H-1-y)` |
| Mirror | `Ctrl+Alt+H` | `(W-1-x, y)` |
| Rotate Left | `Ctrl+Alt+Left` | `(W-1-y, x)` |
| Rotate Right | `Ctrl+Alt+Right` | `(y, H-1-x)` |
| Rotate 180 | `Ctrl+Alt+Down` | `(W-1-x, H-1-y)` |

- `TransformedPixelSource` 使用整数仿射映射惰性读取原始像素；连续变换会合并到根像素源，不形成无限代理链；
- 90° 旋转交换宽高；规则 Bayer 的新 pattern 根据变换后的 2×2 色彩排列重新推导，Gr/Gb 的物理来源仍由像素源保留；
- 即时预览最长边限制为 1024，最多约 1.05 M 个样本；精确像素、Pixel Info 和统计继续通过惰性源读取；
- 预览在后台生成并支持取消/世代号失效，不阻塞 UI，也不允许旧任务覆盖撤销后的状态；
- 维度和仿射偏移使用有边界的 64 位整数，并为组合运算预留溢出空间。

## 5. 统一刷新链路

撤销、重做或处理成功后统一执行：

1. 取消/失效 Pixel Statistics、Filter、Demosaic、Bayer Extract 和 Image Transform 在途任务；
2. 从 `DocumentSession` 恢复显示源、Demosaic 输入和提取上下文；
3. 失效坐标与像素缓存，刷新视口和预览直方图；
4. 同步 Display 控件、Undo/Redo、五项变换动作和各工具可用性；
5. 更新 Bayer Extract、Filter、Demosaic、Pixel Statistics 子窗口的数据源；
6. 若撤销前统计窗口可见、图像尺寸不变且 ROI 仍有效，自动在恢复后的源上重新统计；尺寸变化时清除失效 ROI。
