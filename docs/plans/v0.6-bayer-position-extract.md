# V0.6 Bayer Position Extract 优化方案

## 工具定义

Bayer Channel Extract 是周期位置采样与重组工具，不执行 RGB 渲染或颜色推断。n×m 矩阵表示原图上的最小重复单元；选中的坐标在每个重复单元中被保留，再按指定紧凑顺序组合为新的灰度 RAW 视图。

基准语义：对于尺寸为 W×H 的原图，选择 2×2 左上角 `(0,0)` 时，结果像素 `(x,y)` 必须读取原图 `(2x,2y)`。在尺寸均可整除时结果为 `W/2 × H/2`，即标准 Bayer 的一个独立 channel。

同一模型直接覆盖：

- 标准 Bayer：2×2 重复单元；
- Quad Bayer：4×4 重复单元；
- Hex Bayer：8×8 重复单元；
- 特殊 pattern：1×1～16×16 自定义重复单元，可保存和重新加载。

提取不要求原图元数据必须是 RGGB/BGGR/GRBG/GBRG。只要输入是非标准图片的 RAW 像素源，即使 `BayerPattern=None`，也允许按自定义坐标提取。

## 原图隔离

每次提取请求固定使用 `DocumentSession::original()`。前一次提取结果只作为显示源，不会成为下一次提取的输入。因此先提取 2×2 左上角、再选择右上角时，两次都直接采样完整原图。

结果继续使用只读 `IPixelSource` 坐标映射，不复制整幅大图；V0.6.1 后非全选结果仅生成最长边不超过 1024 的显示预览，全选则直接复用原图预览。

## V0.6 界面

- 删除 `Use full image`、ROI 坐标和尺寸控件，固定处理整幅原图。
- 删除 CSV 导出入口和选中数量标签。
- 结果状态只显示结果尺寸和可选边缘提示，不再显示冗长的 mask/selected 描述。
- 矩阵单元不显示文字，只在顶部标 X、左侧标 Y；精确坐标仍保留在工具提示中。
- 2×2 单元窗口约 420×390，矩阵增大时窗口高度和可滚动区域同步增长。
- Pattern 和 packing 下拉框使用固定紧凑宽度，并显式设置弹出列表前景、背景和选中色，避免 4×4/8×8 文字不可见。

## 验证

- 2×2 四角分别验证源坐标和结果尺寸。
- 4×4、8×8 指定位置验证 Quad/Hex 周期采样。
- `BayerPattern=None` 的 3×2 特殊 pattern 验证。
- UI 验证无 ROI、无 CSV、无单元文字、存在坐标轴、紧凑下拉框和动态高度。
