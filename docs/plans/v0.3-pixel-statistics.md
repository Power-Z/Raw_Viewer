# V0.3 Pixel Statistics 可行性与实施方案

> V0.7.3 已将统计源和选择交互分别更新为“当前显示 RAW 管线”和“按下—拖拽—松开”；V0.7.4 又将通道下拉改为四通道拆分选项，并把图表参数移入 Preferences。本文件保留 V0.3 初始实现记录，现行定义见 `v0.7.3-pixel-statistics-optimization.md` 和 `v0.7.4-pixel-statistics-channels-preferences.md`。

## 1. 结论

V0.3 像素统计可在当前只读 `IPixelSource` 和完整 Grayscale16 显示路径上实现，不需要复制整幅 RAW，也不改变原始数据。统计任务在 Qt 线程池中顺序扫描源像素，UI 线程只维护选择框、进度和有界图表数据。

## 2. 统计口径

- 功能仅对带有效 Bayer pattern 的原始 RAW 开放；标准 JPG/PNG/BMP 不开放。
- 矩形拖拽的按下与松开坐标均包含在 ROI 内；例如 `(0,0) → (1,1)` 包含 4 个像素。
- `Status`：对 ROI 原始样本计算 count、min、max、mean、population standard deviation，并生成灰度直方图。
- `Horizontal Box`：ROI 每一列沿 Y 方向平均，得到长度为 ROI 宽度的 profile；统计值针对该 profile。
- `Vertical Box`：ROI 每一行沿 X 方向平均，得到长度为 ROI 高度的 profile；统计值针对该 profile。
- `Line`：两端点均包含，按最长轴步数进行最近邻采样；横轴为累计欧氏距离，统计值针对线上的有效样本。
- `WB`：保留入口和界面位置，V0.3 不执行计算。
- 通道可选 All、R、Gr、Gb、B；选定通道后，其他 Bayer 位置不参与统计。
- NaN、Inf 和无效像素不进入 count 与统计量；无有效样本返回明确错误。

## 3. 数值与性能方案

- mean/std 使用 Welford 在线算法，避免大数求和和差平方导致的精度损失。
- count 使用 `uint64_t`，坐标、ROI 和进度计算使用受检 64 位范围。
- UInt8/UInt16/UInt32 直方图使用完整标量域，默认 256 bins，可选 64～1024；不会分配 65536 或更大的全范围数组。
- Status 内存复杂度为 `O(histogram bins)`；Horizontal/Vertical/Line 的计算结果统计完整 profile，但图表最多保存 65,536 个降采样点。
- 每 4,096 个源样本检查一次取消标志；进度通过共享原子 permille 值发布。
- 每次计算带 generation 和 cancellation token；切换模式、打开新图或关闭窗口后，旧结果不能覆盖新文档。

## 4. UI 与交互

- 工具英文名为 `Pixel Statistics`。
- 子窗口严格使用顶部模式区、中部结果控制区、底部图表区，stretch 比例为 `1:2:5`。
- Status、Horizontal Box、Vertical Box 使用矩形选择；Line 使用线段选择。
- 左键按下固定起点，保持按下移动鼠标时实时显示选择轮廓，松开左键固定终点并启动后台统计。
- 中部提供 Bayer 通道、histogram bins、grid、data points、histogram fill、line width、进度和取消控制。
- 底部使用自绘 Qt 图表，避免新增 Qt Charts 运行时依赖；支持直方图和 profile 折线。

## 5. 验收证据

- `DocumentSessionTest::calculatesStatusAndProfilesFromOriginalBayerSamples`：Status、Horizontal、Vertical、Line 手算黄金值。
- `DocumentSessionTest::filtersStatisticsByBayerChannelAndCancels`：Bayer 分通道与取消。
- `PixelStatisticsUiTest::completesRectangleAndLineWithDrag`：按下—拖拽—松开坐标和矩形/Line 模式。
- `PixelStatisticsUiTest::exposesFiveModesAndOneTwoFiveLayout`：五个入口和 `1:2:5` 布局。
- `DecoderTest::verifiesApprovedFlatSampleWhenConfigured`：11776×8842 实际 RAW 的 104,123,392 个样本完整统计；Release 测试结果与 NumPy 黄金值一致。
