# V0.7.1 连续像素标注与 Pixel Info 精简

## 需求与实现

| ID | 需求 | 实现与验收 |
|---|---|---|
| V0.7.1-01 | 缩放和移动时标注完全跟随像素且不闪烁 | 删除 V0.7 的拖拽暂停状态和滚轮 80 ms 恢复定时器；每次视口绘制均使用当前 `offset + sourceCoordinate × zoom` 计算文字位置。 |
| V0.7.1-02 | 达到显示条件后不能遗漏像素标注 | 删除 `maximumLabels=200` 抽样和 Pixel Info 中的标签上限；缩放达到固定 40 px/像素阈值后遍历全部可见像素。25×20 可见区域验证 500 次像素查询、无抽样遗漏。 |
| V0.7.1-03 | Pixel Info 只保留三个功能 | 窗口仅保留“像素值标注”、“Bayer mesh”、“Bayer pattern”三个复选框，删除 Raw/Display/RGB 手动选择、阈值和标签数量控件。 |
| V0.7.1-04 | 像素值根据图像类型自动显示 | Flat/Camera RAW 显示原始数值；Standard RGB 图片自动显示 `R,G,B` 三个显示通道值，不需要用户切换类型。 |
| V0.7.1-05 | Bayer mesh 使用 RGGB 四色遮罩 | R、Gr、Gb、B 分别使用半透明红、亮绿、深绿、蓝遮罩；Gr/Gb 颜色独立。无 Bayer pattern 时不绘制遮罩。 |
| V0.7.1-06 | Bayer pattern 标记位于右下角且高度约 1/7 | `R/Gr/Gb/B` 使用 `round(zoom/7)` 字体并在各像素右下角对齐；像素值字体调整为 `round(zoom/6)` 并保持居中。 |

## 行为说明

- V0.7.1 明确取代 V0.7 的“交互期间暂停标注”策略。图像、数值、遮罩与 Pattern 标记在拖拽及缩放的每一帧共同移动。
- 固定 40 px/像素显示阈值仍然存在，但不再暴露在 Pixel Info 窗口中；达到阈值后不允许为了标签上限跳过任何可见像素。
- 默认视口状态不启用任何叠加层；打开 Pixel Info 后默认启用像素值和 Bayer pattern，Bayer mesh 默认关闭。
- 全量标注仅访问当前可见区域，不扫描完整 RAW，也不建立整图标签缓存。

## 自动化验证

- `rendersContinuousCompletePixelValues`：验证 RAW 黑白字体、1/6 字高、拖拽后文字中心同步移动、滚轮后立即存在，并对 25×20 可见区域检查恰好 500 次查询。
- `rendersBayerMaskAndPatternLabels`：验证 RGGB 四个遮罩位置、Gr/Gb 颜色差异、右下角 Pattern 文字及纯遮罩模式不读取原始像素。
- `simplifiesPixelInfoAndAutoFormatsRgb`：验证 Pixel Info 只有三个复选框、无阈值控件，并通过标准 RGB 图离屏渲染确认自动生成三通道数值。
