# V0.7.4 Pixel Statistics 通道与偏好设置优化

## 需求与实现

| ID | 需求 | 实现与验收 |
|---|---|---|
| V0.7.4-01 | Channel 改为可选项；启用后显示 R/Gr/Gb/B 四个结果 | 主窗口不再提供通道下拉框，改为 `Bayer channels` 复选项。关闭时显示 All 单结果；开启时底部切换到 2×2 的 R/Gr/Gb/B 四面板，每个面板独立显示统计摘要和直方图/profile。无规则 Bayer 排列的提取结果会禁用该选项。 |
| V0.7.4-02 | 从主窗口移除 Line width，并把 Line width、Histogram Bins、Data points 等移入 Preferences | `偏好 → Pixel Statistics…` 提供 Line width、Histogram bins、Data points、Grid 和 Histogram fill；设置通过 `QSettings` 持久化。Line width 默认值由 2 改为 1，统计主窗口只保留 Bayer channels、选择、结果和进度。 |

## 四通道计算策略

- `PixelStatisticsService::executeChannels` 在一次 ROI 遍历中读取每个像素一次，再按 Bayer 坐标把样本分流到 R/Gr/Gb/B 四组 Welford 归约器；不会为了四个结果扫描四遍 RAW；
- Status 同时维护四个有界直方图；Horizontal/Vertical 同时维护四组行列 profile；Line 沿路径采样一次并分流；
- 每个通道保留独立 count/min/max/mean/population std 和图表数据；ROI 未覆盖某通道时，该面板明确显示无样本，不影响其他三个结果；
- 取消、generation 失效保护、进度和 65,536 点图表上限保持有效；四通道统计的额外内存只与四组直方图/profile 有关，不复制 RAW。

## 偏好设置

| 键 | 默认值 | 范围/含义 |
|---|---:|---|
| `pixelStatistics/lineWidth` | 1 px | 1～5 px |
| `pixelStatistics/histogramBins` | 256 | 16～4096 |
| `pixelStatistics/showDataPoints` | false | profile 数据点 |
| `pixelStatistics/showGrid` | true | 图表网格 |
| `pixelStatistics/fillHistogram` | true | 直方图填充 |

## 自动化验证

- `calculatesFourChannelsInSinglePass`：4×4 RGGB 共读取 16 次而不是 64 次，并验证四通道 count 和 mean 黄金值；
- `rendersFourBayerChannelResultPanes`：验证 Channel 为复选项、四面板切换和 R/Gr/Gb/B 面板完整；
- `statisticsComputesFourChannelsFromMainWindow`：主窗口端到端统计 10×10 RGGB，四个面板分别得到 25 个样本；
- `persistsPixelStatisticsPreferences`：验证偏好菜单、默认 1 px、Bins/Data points 写入和重新读取；
- `exposesCompactTechnicalPaneLayout`：验证统计窗口不再含 Channel/Bins/Line width 下拉控件，非规则 Bayer 结果禁用通道拆分。
