# V0.4 Bayer Channel Extract 优化方案

## 目标

把固定的 2×2 R/Gr/Gb/B 通道提取扩展为可配置的 n×m 重复掩码。用户在矩阵中选择要保留的源像素，选择行优先或列优先后，工具对完整图像或 ROI 重复应用同一掩码。

## 数据语义

- 掩码按源坐标行优先保存，选中值表示保留该位置，未选中值不进入结果。
- 行优先按 `y → x` 枚举选中位置，并在每个输出单元内从左到右、从上到下紧凑排列。
- 列优先按 `x → y` 枚举选中位置，并在每个输出单元内从上到下、从左到右紧凑排列。
- 每个源重复单元映射到固定大小的矩形输出单元；末行或末列不足时可能有一个无效补位。
- 源宽高不是掩码整数倍时，右侧和底部使用部分单元。只有仍位于源区域内的已选像素有效；无效补位显示为黑色且不写入 CSV。
- 输出像素通过 `IPixelSource` 坐标映射按需读取原图，不创建整幅提取副本。仅生成最长边不超过 2048 的有界预览。

## UI 与配置

- 顶部提供 2×2、4×4、8×8 预设和行/列优先选择。
- 矩阵单元使用灰色未选、蓝色选中、悬停描边，并显示 Bayer 通道及单元内坐标。
- 支持 1×1 到 16×16 自定义编辑、命名、保存、加载和删除；自定义配置用 `QSettings` 持久化，内置预设只读。
- 提供全选、清空、反选和已选数量反馈。
- 对非整倍数源区域，在开始后台任务前显示确认警告。

## 验证

- 应用层黄金测试覆盖任意三点掩码的行优先、列优先、坐标正反映射、矩形补位和奇数尺寸边缘。
- 基础设施测试覆盖 CSV 输出坐标与样本值，并跳过边缘/矩形补位。
- UI 测试覆盖三个预设、矩阵尺寸、选中状态、行列优先、边缘检测及自定义配置持久化。
