# V0.6.2 Bayer Extract 紧凑界面优化

## 需求与实现

| ID | 需求 | 实现与验收 |
|---|---|---|
| V0.6.2-01 | 小矩阵区域提高到窗口垂直方向约 2/5 | Pattern 控制区与矩阵区拆分；2×2 默认矩阵滚动区为 150 px，默认窗口为 375 px，自动化测试验证占比不低于 2/5。 |
| V0.6.2-02 | `Pattern & packing` 简化为 `Pattern`，标题保持 1.5 倍字体行高 | 标题固定为字体高度的 1.5 倍；控制卡使用固定垂直 size policy，不吸收矩阵区的缩放空间。 |
| V0.6.2-03 | 自定义配置默认隐藏，从 Pattern 下拉框选择后显示 | 下拉框末尾增加 `Custom`；预设默认隐藏名称、W/H、Save/Delete，选择 `Custom` 或已保存的自定义项时展开。自定义项始终插入到 `Custom` 之前。 |
| V0.6.2-04 | 矩阵块使用正方形并缩小间距 | 单元固定为 24×24 方形、无圆角，网格间距从 7 px 降为 3 px。 |
| V0.6.2-05 | 排列选项仅保留英文，并提供问号说明 | 选项为 `Row-major` / `Column-major`；右侧 `?` 说明行优先与列优先的枚举、重组顺序。 |
| V0.6.2-06 | 子窗口整体缩小和简化 | 默认 2×2 窗口由不小于 420×390 缩小为 340×375；8×8 仍按内容增大，切回 2×2 后精确恢复。 |

## 行为边界

- V0.6.2 仅改变工具界面与配置入口，不改变原始 RAW 坐标枚举、行/列优先语义、只读提取结果和后台任务。
- 选择 `Custom` 时保留当前矩阵尺寸和勾选状态，便于从预设复制后微调；名称清空以避免覆盖受保护的预设。
- 已保存自定义配置继续持久化，并在下次打开时显示在预设与 `Custom` 入口之间。

## 自动化验证

`PixelStatisticsUiTest::editsAndPersistsBayerMaskPatterns` 覆盖：

- Pattern 标题、1.5 倍行高、英文排列项和帮助按钮；
- 自定义编辑区默认隐藏、选择 `Custom` 后显示；
- 24×24 方形单元、3 px 间距和默认矩阵区 2/5 占比；
- 默认紧凑尺寸、2×2 → 8×8 → 2×2 双向恢复；
- 自定义配置保存、排序及重启后的持久化加载。
