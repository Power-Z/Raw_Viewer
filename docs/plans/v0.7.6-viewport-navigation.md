# V0.7.6 RAW 视口综合导航优化

## 需求与实现

| 需求 ID | 行为 | 实现 |
| --- | --- | --- |
| V0.7.6-01 | 工具占用左键时仍可拖拽 RAW | `ImageViewport` 支持鼠标中键按下、移动、释放完成平移；中键优先进入导航，不触发 Pixel Statistics 的矩形或 Line 选择，释放后恢复十字光标。无工具时原有左键平移继续保留。 |
| V0.7.6-02 | 顶部、底部显示严格对齐的像素标尺 | 视口定义唯一有效画布矩形，图像绘制、鼠标坐标和两条水平标尺共同使用 `widget = offset + source × zoom`。标尺根据缩放选择 1/2/5×10ⁿ 的主刻度，主刻度间距至少约 80 px，细刻度不小于一个源像素。刻度位于像素边界，不使用预览尺寸推算。 |
| V0.7.6-03 | 右上角显示全图缩略导航 | 画布右上角绘制半透明、最长 180×120 px 的完整预览，预览位置和大小不随平移缩放改变；当前画布与全图的交集按同一源坐标变换映射为橙色矩形。缩略图只复用已有有界 preview，不读取或复制整幅 RAW。 |
| V0.7.6-04 | 底部、右侧滚动条调整显示区域 | 添加水平和垂直 `QScrollBar`。图像超过有效画布时启用，范围按显示像素长度映射，最大使用 20 亿级离散范围以兼容 200 MP 大图高倍缩放；滚动、滚轮缩放和鼠标平移会双向同步。图像完整可见时滚动条保留但禁用。 |
| V0.7.6-05 | 默认仅显示像素值 | Pixel Info 仍默认启用像素值，Bayer mesh 和 Bayer pattern 均默认关闭；用户可在 Pixel Info 中手动开启。 |

## 坐标与性能约束

- 顶部标尺 24 px，底部标尺 24 px，底部和右侧滚动条 14 px；这些区域从有效画布中扣除，鼠标位于标尺或滚动条时不会发布图像内坐标。
- `offset_` 始终是源图 `(0,0)` 在 QWidget 中的位置，`zoom_` 是源像素到设备像素的比例。标尺、像素标注、统计选区、缩略图视野框和滚动条都从这两个量计算。
- 视口导航只修改显示状态，不改变 `DecodedImage`、原始像素源或处理管线。
- 滚动条使用有界整数范围，但回写 `offset_` 时按双精度比例恢复，不将超大图显示尺寸转换为 32 位像素总数。

## 验证

- `supportsMiddleButtonPanDuringStatisticsSelection`：统计矩形工具激活时，中键平移改变当前源坐标、不发布统计选择，释放后恢复十字光标；
- `rendersRulersOverviewAndSynchronizedScrollBars`：验证上下标尺的源坐标 5 刻度与同一图像像素边界对齐；验证固定全图缩略图和缩放后变小的视野框；验证滚动条位于底部/右侧、超出画布后启用且拖动改变源坐标；
- 原有矩形/Line 选择、连续像素标注、Bayer mesh/pattern、提取后标注和四通道统计 UI 回归继续通过；
- Windows MSVC Debug/Release 构建与 CTest 均通过。
