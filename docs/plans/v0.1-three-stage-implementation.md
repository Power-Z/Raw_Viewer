# Raw Viewer 三阶段实施方案

- 状态：已接受
- 设计基线：`docs/architecture/v0.1-architecture.md`
- 目标：在三个可验收、可回退的阶段内形成 Raw Viewer 初步功能

## 1. 实施原则

- 每个阶段都必须产生可以运行和演示的版本，不建立长期“不可运行”分支；
- 先验证数据正确性，再做 GPU 和性能优化；
- 大图接口从第一阶段存在，大图优化在第三阶段兑现；
- 原始数据不可变和分层依赖从第一行代码开始执行，不能事后重构补救；
- 每项任务关联需求 ID、测试和验收证据；
- 未满足阶段出口条件时不进入下一阶段。

## 2. 阶段总览

| 阶段 | 建议版本 | 目标 | 用户可见结果 |
|---|---|---|---|
| 第一步 | V0.2 | 工程骨架与基础浏览闭环 | 可从文件树/拖拽打开普通图片和基础 RAW，缩放、平移、查看状态 |
| 第二步 | V0.3 | 非破坏处理与基础分析 | 可调显示、五步撤销、像素信息、Bayer 提取、ROI 基础统计、双图对比 |
| 第三步 | V0.4 | 大图与完整初步工具 | 200 MP RAW 瓦片浏览、完整统计 profile、取消/进度、可发布安装包 |

## 3. 第一步：工程骨架与基础浏览闭环（V0.2）

### 3.1 目标

建立可持续构建、测试和发布的 C++/Qt 工程，并完成“选择文件 → 正确解码 → 显示 → 交互”的最小闭环。

### 3.2 工作包

#### P1-01 工具链与分层骨架

- 建立 `apps/`、`src/domain`、`src/application`、`src/infrastructure`、`src/presentation`；
- 配置 C++20、Qt 6、CMake Presets、CTest；
- 每层独立 target，增加依赖方向检查；
- Windows GitHub Actions 构建 Debug/Release；
- 建立本地日志、错误码和版本信息。

#### P1-02 主窗口框架

- 菜单：文件、编辑、偏好、Tool、帮助；
- 状态栏；
- 20/60/20 可调三栏布局；
- RAW 参数区、文件树、统计占位、显示控制占位、工具入口；
- Dark、Light、Gray、Yellow、Red 主题；
- About 和版本说明入口。

#### P1-03 文件浏览与打开

- 只读 `QFileSystemModel`；
- 路径输入、回车进入、刷新、上一级、展开目录、双击文件；
- 图像视口拖放；
- 使用 `QImageReader` 打开 JPG/PNG/BMP；
- 结构化错误提示。

#### P1-04 基础 RAW 解码

- `RawDescriptor` 和 checked size validation；
- 内容签名优先的 `ImageFormatProbe`；
- 平面 `.raw/.RAW/.bin` 使用 `FlatBinaryRawDecoder`；
- `headerBytes`、width、height、stride；
- byte-aligned UInt8、UInt16、UInt32、Float32；
- little/big endian；
- 文档级 Bayer pattern 和 sensor black level；
- 小型合成 fixture 覆盖端序、头偏移、截断和溢出。

#### P1-04B 相机 RAW 容器

- 集成主线 LibRaw 0.22.x 动态库，不启用 GPL demosaic packs；
- TIFF/DNG/厂商相机 RAW 与平面 RAW 分流；
- 提取相机、RAW/活动区尺寸、边距、Bayer、黑白电平、方向和缩略图；
- 获取未处理 UInt16 Bayer 数组并接入不可变 `OriginalData`；
- 使用 `CAMERA-HB-X2D-001` 做本地集成与约 100 MP 基准；
- LibRaw 不支持或容器损坏时不回退为盲目平面解码。

#### P1-05 基础视图交互

- CPU 渲染路径；
- 左键拖动；
- 鼠标锚点滚轮缩放；
- 坐标变换和越界处理；
- 状态栏显示坐标、值、尺寸、格式和缩放；
- 后台打开任务和关闭/切换文件的世代号保护。

### 3.3 阶段出口

- 干净 Windows x64 环境可按 README 一键配置、构建和测试；
- 文件树和拖放均能打开一份 JPG、PNG、BMP 和四种小型 RAW fixture；
- 8/16/32-bit 的已知像素值与黄金值一致；
- Hasselblad 样本被识别为 11904×8842 UInt16 RGGB，而不是按扩展名平面解释；
- 改变端序、头偏移或 stride 后显示结果可预测；
- 截断或尺寸溢出文件被拒绝，软件不崩溃、不大额分配；
- 100% 和非整数缩放下鼠标锚点误差不超过 1 个屏幕像素；
- 打开任务期间 UI 可移动和取消；
- 分层 target 没有反向依赖。

### 3.4 明确不做

- 完整大图 GPU 性能承诺；
- 处理撤销；
- ROI 统计和曲线；
- packed 10/12/14-bit；
- 二进制插件。

## 4. 第二步：非破坏处理与基础分析（V0.3）

### 4.1 目标

建立原始/中间/显示三层数据和工具框架，形成可撤销的显示处理与像素分析闭环。

### 4.2 工作包

#### P2-01 非破坏处理管线

- 不可变 `OriginalData`；
- `ProcessingPipeline` 和 revision；
- `sensorBlackLevel` 与 `displayBlackPoint` 分离；
- WLV/displayWhitePoint、Gamma；
- 参数校验、节流和缓存失效；
- CPU 参考实现。

#### P2-02 五步撤销

- 每文档独立命令栈；
- 处理参数命令、命令合并、五步限制；
- 编辑菜单 Undo/Redo 状态；
- 撤销/重做不复制整图；
- 文档切换不会串栈。

#### P2-03 Pixel Info

- 原始信号、处理后值和 RGB 显示开关；
- 像素值 overlay 阈值和标签上限；
- Bayer mesh；
- RGGB/BGGR/GRBG/GBRG 英文字标注；
- 状态栏查询节流。

#### P2-04 Bayer Extract

- R/Gr/Gb/B 提取；
- 原坐标与通道坐标转换；
- 单通道显示和导出接口；
- 奇数尺寸和 ROI 边界测试。

#### P2-05 ROI Status Statistics

- 矩形 ROI；
- count/min/max/mean/variance；
- 灰度直方图；
- RAW 全部样本与 Bayer 分通道；
- 后台执行、进度、取消和过期结果保护；
- CSV 导出。

#### P2-06 基础双图对比

- 两图并排；
- 默认同步缩放/平移；
- `Alt + 左键` 单独平移；
- 不同尺寸的坐标同步与越界显示；
- 当前活动文档和工具状态清晰可见。

### 4.3 阶段出口

- 任意处理前后原文件 SHA-256 不变；
- 连续滑块拖动合并为一次撤销，最多可撤销五个逻辑操作；
- Pixel Info 在四种 Bayer pattern 下标注正确；
- ROI 统计与手算/脚本黄金值在规定误差内一致；
- 统计任务取消后 200 ms 内停止发布进度，过期结果不覆盖新结果；
- 双图同步变换的源坐标误差不超过 0.5 像素；
- 处理、统计和 UI 测试进入 CI。

## 5. 第三步：大图与完整初步工具（V0.4）

### 5.1 目标

兑现 200 MP / 400 MB RAW 的可用性，补齐 Horizontal、Vertical、Line 统计和可发布质量。

### 5.2 工作包

#### P3-01 文件映射与瓦片源

- 平面 RAW 使用只读映射窗口与 Windows 对齐处理；
- 相机 RAW 评估容器分块能力；无法随机读取时只保留一份不可变解码 mosaic，禁止后续整图复制；
- 512×512 初始瓦片；
- 可见区请求和一圈预取；
- 参数/文档世代号；
- 文件外部变化检测。

#### P3-02 金字塔与有界缓存

- 按需 1/2 多级金字塔；
- LRU 内存预算；
- 缓存键和失效测试；
- 内存不足降级；
- 记录命中率、解码耗时和峰值工作集。

#### P3-03 GPU 瓦片渲染

- `QOpenGLWidget` 渲染适配器；
- 纹理上传队列和复用；
- CPU 回退；
- 设备/上下文丢失处理；
- 像素 overlay 批量绘制。

#### P3-04 完整 Pixel Statistics

- Horizontal area；
- Vertical area；
- Line profile；
- 稳定分块归约；
- 曲线降采样；
- 结果与图表导出。

#### P3-05 性能、稳定性与发布

- 固定 200 MP / 400 MB 合法样本；
- 打开、首次预览、平移、缩放、统计、取消基准；
- 12 小时长稳测试和重复开关文件测试；
- 安装包、卸载、版本信息、依赖许可证；
- 发布检查表和恢复演练。

### 5.3 建议性能门槛

以下是起始门槛，必须在确定最低测试设备后校准：

| 场景 | 初始目标 |
|---|---:|
| 400 MB byte-aligned RAW 参数确认到低分辨率首屏 | ≤ 3 秒 |
| 已有可见瓦片后的平移反馈 | ≤ 100 ms |
| 缩放交互视觉更新 | ≤ 100 ms |
| 用户取消长任务到任务停止发布结果 | ≤ 200 ms |
| 仅浏览时额外工作集（不含文件映射） | ≤ 1.5 GB |
| 过期瓦片/统计结果污染当前文档 | 0 次 |

### 5.4 阶段出口

- 固定大样本在最低设备上达到经确认的性能门槛；
- 平移、缩放、处理和统计不需要整图多份复制；
- 缓存超预算时可预测淘汰，不崩溃；
- GPU 不可用时仍能通过 CPU 路径打开和浏览；
- 三种 profile 与黄金数据一致；
- 安装、升级、卸载和全新克隆构建验证通过；
- V0.4 发布检查表完成。

## 6. 跨阶段任务

每个阶段都要执行：

- 更新需求追踪矩阵；
- 更新 ADR 状态；
- 登记新风险和技术债务；
- 登记新增测试样本及授权；
- 更新 Changelog 和项目状态；
- 检查第三方许可证和安全告警；
- 在 Pull Request 中记录验证命令和结果。

## 7. 编码前确认状态

已于 2026-07-31 确认：

1. 首发 Windows 10/11 x64；
2. Qt 开发期按 LGPL 动态链接方案，正式发布前复审；
3. UInt32 与 Float32 都在第一阶段支持；
4. Horizontal/Vertical 采用架构文档第 11 节定义；
5. 使用架构文档初始性能目标；
6. 基准设备为 Windows 11 x64、Intel Core Ultra 5、16 GiB 显存；
7. `CAMERA-HB-X2D-001` 允许本项目本地测试。

尚未满足：

- 200 MP / 400 MB 合法样本已批准延期到 V0.4 准备，不阻塞 V0.2；
- GPU 型号、系统内存和磁盘规格仍需补齐后才能形成完整最低配置；
- 正式分发前仍须完成 Qt 与 LibRaw 许可清单复审。
