# V0.7.10 像素标注与实时示例方案

## 1. 需求

- PNG/JPG 等标准图像及 Demosaic/ISP RGB 输出按三行显示 `R n`、`G n`、`B n`，放在像素左下角；
- 排查连续打开第二张图后像素标注坐标错位；
- Pixel Info 右侧提供 4×4 标准 RGGB 示例，实时展示三个选项的效果，窗口不使用圆角卡片。

## 2. 排查结论

像素缓存会在 `setImage()` 时失效，鼠标坐标也使用当前 `metadata.width/height`，没有发现旧像素缓存直接复用到第二张图。风险位于交互状态：如果旧图在鼠标释放前被替换，`dragging_`、`lastMouse_` 或区域选择仍可能保留；下一次 mouse-move 会把旧锚点增量应用到新图偏移。同时，视口没有在换图瞬间主动发布坐标无效，状态栏只能等待后续鼠标事件同步。

## 3. 实现

### 3.1 RGB 标注

- 标准图像和 `displayReadyRgb` 输出继续通过 `queryPixelInfo()` 得到显示 RGB；
- 每个可见 RGB 像素缓存三个独立 `QStaticText`，避免 Qt 将带换行字符串按单行静态布局；
- 三行共享现有黑/白背景对比判断，左边距和下边距均为像素显示尺寸的约 1/28；
- RAW 标量值仍保持居中，Bayer pattern 仍在右下角，避免改变已有 RAW 操作习惯。

### 3.2 换图同步

非 `preserveView` 的新图设置会在安装图像前一次性：

- 结束拖拽并清除旧鼠标锚点；
- 清除未完成的统计选择；
- 重置 zoom、offset 和 fit mode；
- 失效像素与精确显示缓存；
- 发布 `imageCoordinateChanged(0, 0, false)`，使状态栏立即离开旧坐标。

处理管线中尺寸不变且明确要求 `preserveView` 的显示映射、Filter/Demosaic 更新不执行该重置。

### 3.3 Pixel Info 示例

- 子窗口使用左右直角区域：左侧三个复选项，右侧 4×4 RGGB 示例；
- 示例使用不同灰度背景，并复用主视口的 R/Gr/Gb/B mesh 和 pattern 配色；
- 每次复选框切换先更新示例，再发布 `optionsChanged` 到主视口；
- 示例声明固定 4 列、4 行属性，便于 UI 自动化验证。

## 4. 验证

- 1×1 RGB 12/34/56 离屏渲染的文字从像素左侧开始，底部超过像素高度 80%，三行总高度显著大于单行；
- 在第一张图按下左键但不释放，切换到 10×10 第二张图后先收到无效坐标，鼠标移到中心返回 `(5,5)`；
- Pixel Info 示例为 4×4，依次切换 mesh、pattern 和 value 后的离屏帧均不同，且窗口样式不包含 `border-radius`。
