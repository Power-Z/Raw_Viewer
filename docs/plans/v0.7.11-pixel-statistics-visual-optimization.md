# V0.7.11 像素统计与 RGB 标注视觉优化方案

## 1. 需求范围

- RGB 图像像素值标注缩小为 V0.7.10 字号的 60%，R/G/B 三行使用对应通道颜色；
- Pixel Statistics 子窗口保持直角视觉，移除 MODE、ANALYSIS、PLOT 三个冗余标题并压缩顶部与分析区；
- COUNT、MEAN、MIN、MAX、STD 标题字号增加 40%，移除进度条上方的重复状态文字；
- 图表在所有主题下使用纯黑数据线，绘图区固定为 RGB(207,207,207)，收窄数据线、坐标轴和边框；
- 鼠标靠近曲线或直方图顶部时显示连接数据点与 X/Y 轴的引导线。

需求第 4 项结尾未给出“整个 analysis 区域的高度和宽度”的具体动作，本次按上下文解释为缩小该区域占用：内容改为三行紧凑布局，宽度继续跟随窗口，不设置会截断统计值的固定宽度。第 6 项为空，不产生实现项。

## 2. UI 设计

- 模式区只保留五个模式按钮和关闭按钮，采用固定内容高度；
- 分析区依次放置通道/选择信息、五项指标、进度与取消按钮，不再单独显示状态标签；
- 进度状态只由进度条内部的 Ready、Calculating 和 Complete 文本表达；
- 图表区直接承载单结果或四通道结果，不再占用一行显示 PLOT。

所有统计面板、通道卡片和模式按钮显式使用 `border-radius: 0px`。Windows 11 下同时通过 DWM 窗口角偏好关闭原生顶层窗口圆角；Windows 10 不支持该属性时安全忽略。指标标题由 10 px 调整为 14 px，符合增加 40% 的要求。

## 3. 绘图与性能

- 曲线和直方图边线使用不依赖 `QPalette::Highlight` 的纯黑色；直方图填充使用低透明度黑色；
- 绘图区先填充 RGB(207,207,207)，外围仍使用当前主题背景，保证轴标签在深浅主题下可读；
- 数据线宽按偏好值的 75% 绘制，最小保持一个物理像素，避免亚像素抗锯齿把纯黑合成为灰色；
- 坐标轴、图框和网格使用 0.5 px cosmetic pen；
- 悬停位置先反算 X 值，再对有序 X 数据二分查找，只检查相邻两个样本。单次移动复杂度为 O(log n)，不随超长 profile 做全量最近点扫描；距离不超过 14 px 时绘制水平和垂直引导线。

## 4. RGB 标注

- RAW 标量值继续使用约 `zoom / 6` 字号并居中，不受本次需求影响；
- RGB 三行改用约 `zoom / 10` 字号，即原 `zoom / 6` 的 60%；
- 明暗背景分别使用高对比的红、绿、蓝色阶，三行仍复用每像素缓存的 `QStaticText`，不会增加像素读取次数或重复文本布局。

## 5. 验证

- UI 自动化验证三处标题和额外状态标签已移除、Mode/Analysis 高度收紧、指标标题至少 14 px 且面板显式直角；
- 深色主题调色板下离屏验证绘图区为 RGB(207,207,207)、数据线包含纯黑像素，靠近曲线后横纵引导线可见；
- 1×1 RGB 离屏验证三行总高度随 60% 字号下降，且红、绿、蓝三类像素均存在；
- Debug 与 Release CTest 均为 4/4 通过。
