# V0.6.3 Bayer Extract 可读性优化

## 需求与实现

| ID | 需求 | 实现与验收 |
|---|---|---|
| V0.6.3-01 | 缩小问号边框，使用常规提示设计 | Packing 帮助改为 18×18、无边框、自动浮起的 `?` 工具按钮，仅在悬停时显示浅色背景。 |
| V0.6.3-02 | 小 pattern 使用更大的方块，并按 2×2、4×4、8×8 比例缩放 | 以 pattern 的最大边为依据：1～2 使用 48 px，3～4 使用 36 px，5～8 使用 24 px，9～16 使用 12 px；对应 4:3:2:1 的尺寸关系。 |
| V0.6.3-03 | 删除顶部 Source 尺寸等信息 | 从对话框布局和 `setSource()` 更新逻辑中移除 Source 标签；源尺寸只保留为部分边缘校验的内部状态。 |

## 布局规则

- 单元仍为无圆角正方形，间距保持 3 px。
- 滚动区尺寸由 `行/列数量 × 当前单元尺寸` 计算，因此更大的 2×2 单元不会被裁切，8×8 和最大 16×16 自定义 pattern 也不会无意义放大窗口。
- 移除 Source 行后，默认 2×2 窗口约为 340×358；矩阵滚动区约 153 px，继续满足 V0.6.2 的约 2/5 占比要求。
- 该变更只影响 UI 显示，不改变 RAW 采样坐标、packing 顺序或提取结果。

## 自动化验证

`PixelStatisticsUiTest::editsAndPersistsBayerMaskPatterns` 新增验证：

- Packing 帮助为 18×18 无大边框的自动浮起按钮；
- 2×2、4×4、8×8 单元分别为 48、36、24 px；
- 16×1 自定义 pattern 单元为 12 px；
- 对话框中不再出现 `Source ...` 标签；
- 动态尺寸切换后，提取请求与自定义配置持久化保持正确。
