# V0.5 Recent Files 实施方案

## 行为

- File 菜单增加 `Recent Files` 子菜单，展示最近十个成功打开的文档，最新项位于顶部。
- 同一路径再次成功打开时更新已保存配置并移动到顶部，不产生重复项。
- 只有解码成功并显示后才写入记录；取消、截断、格式错误和其他失败不会污染历史。
- 点击记录前先把当次成功打开使用的 RAW 参数恢复到左侧控件，再进入统一的异步打开流程。
- 菜单每次展开时检查文件是否仍为普通文件。已删除或被目录替代的路径保留历史位置、标记为不可用并禁用，避免发起无意义的读取。
- 提供清除最近文档记录操作。

## 保存内容

每项保存绝对路径以及 Width、Height、Skip/Header、Row Stride、Scalar Type、Byte Order、Bayer Pattern 和 Sensor Black Level。64 位整数使用十进制字符串写入 JSON，避免 JSON 浮点数对大偏移量造成精度损失。

持久化接口定义在 application 层，`QSettings` 实现在 infrastructure 层，由程序入口注入主窗口，保持表现层不直接依赖基础设施实现。

## 验证

- 验证最多十项及 MRU 顺序。
- 验证重复路径去重、移动到顶部并更新配置。
- 验证超过 `2^53` 的 64 位偏移量可无损保存和加载。
- 验证 Scalar Type、Byte Order、Bayer Pattern 和 Sensor Black Level 完整恢复。
- 验证清除记录。
