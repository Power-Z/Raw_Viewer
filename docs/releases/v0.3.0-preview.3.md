# Raw Viewer v0.3.0 Preview 3

- 发布日期：2026-08-19
- 平台：Windows 10/11 x64
- 发布类型：未签名便携 Preview

## 主要变化

- Pixel Info 增加可见区域缓存，像素值与 Bayer 标注在连续缩放和平移时保持同步；
- Pixel Statistics 改为当前显示 RAW 管线，支持拖拽选择、单遍四 Bayer 通道统计、紧凑技术面板和持久化偏好；
- Bayer Extract 后的像素值和源 Bayer 通道标注保持准确，并确认连续 Extract 始终从 original source 开始；
- RAW 视口增加中键平移、上下像素标尺、全图缩略导航和同步滚动条；
- 新增 Mean、Gaussian、Median Filter，使用 1024 有界预览、可分离卷积、滑动中位数和惰性瓦片；
- 新增 Bilinear、Malvar-He-Cutler、Hamilton-Adams Bayer Demosaic，支持当前 Filter 管线、惰性 RGB 瓦片和输入恢复。

完整行为与操作步骤见 [用户指南](../user-guide.md)，算法与性能方案见 [V0.7.7 Filter](../plans/v0.7.7-filter-tool.md) 和 [V0.7.8 Bayer Demosaic](../plans/v0.7.8-bayer-demosaic.md)。

## Preview 限制

- 二进制未签名，Windows SmartScreen 可能警告；
- 未执行独立安全漏洞扫描、正式法律审查或干净 Windows VM 验收；
- 暂无安装/升级/卸载程序；
- Demosaic 输出为显示映射后的 8-bit RGB，尚未实现白平衡、相机色彩矩阵和完整 tone mapping；
- 双图对比、packed RAW 和最终 GPU 瓦片管线尚未完成。
