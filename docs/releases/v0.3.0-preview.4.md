# Raw Viewer v0.3.0 Preview 4

- 发布日期：2026-08-20
- 平台：Windows 10/11 x64
- 发布类型：未签名便携 Preview

## 主要变化

- 修正 Bayer Extract 输出坐标、源坐标追踪和高倍率精确像素标注，连续 Extract 始终从 original source 开始；
- RGB 像素标注改为紧凑的 R/G/B 三行显示，Pixel Info 增加 4×4 RGGB 实时预览；
- Pixel Statistics 精简布局、增强指标和曲线悬停引导，并统一深浅主题下的图表表现；
- Edit 菜单新增 Flip、Mirror 和 Rotate，五步 Undo/Redo 扩展到显示参数、几何变换、Extract、Filter 与 Demosaic 全管线；
- 右上角直方图改为全分辨率 Bayer/RGB/单通道统计，BLV/WLV 与双手柄、放大窗口保持同步；
- BLV/WLV 拖动采用预览后一次提交，增加输入防抖、连续内存扫描和 65,536-bin 投影缓存，RAW 默认 Gamma 调整为线性 1.0。

完整行为与操作步骤见 [用户指南](../user-guide.md)，设计与性能依据见 [V0.7.9～V0.7.14 方案](../plans/v0.7.14-global-histogram-performance.md)。

GitHub Release 提供：

ZIP 内包含 `RawViewer.exe`、Qt 6.8.3 动态库、LibRaw 0.22.2、MSVC x64 Runtime、`qwindows` 平台插件、README、发布信息和第三方许可证。构建产物不进入 Git 历史，统一作为 GitHub Release assets 保存。

## Preview 限制

- 二进制未签名，Windows SmartScreen 可能警告；
- 未执行独立安全漏洞扫描、正式法律审查或干净 Windows VM 验收；
- 暂无安装/升级/卸载程序；
- Demosaic 输出为显示映射后的 8-bit RGB，尚未实现白平衡、相机色彩矩阵和完整 tone mapping；
- 双图对比、packed RAW 和最终 GPU 瓦片管线尚未完成。
