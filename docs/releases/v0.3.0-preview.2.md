# Raw Viewer v0.3.0 Preview 2

- 发布日期：2026-08-18
- 平台：Windows 10/11 x64
- 发布类型：未签名便携 Preview

## 主要变化

- Bayer Extract 支持 2×2、4×4、8×8 和 1×1～16×16 自定义位置矩阵；
- 每次从原始全图提取，支持 Row-major/Column-major、自定义配置持久化和部分边缘确认；
- 全选 pattern 使用零拷贝恒等路径，单位置提取使用坐标预计算和 1024 有界 signal preview；
- File 菜单增加最近 10 个文档、完整 RAW 参数恢复、缺失文件处理和清除记录；
- Pixel Info 改为自动 RAW/RGB 数值、全部可见像素连续标注、RGGB 四色遮罩和右下角 Pattern；
- Bayer Extract 与 Pixel Info 子窗口完成 V0.6.1～V0.7.1 的紧凑 UI 和交互修复。

完整行为与操作步骤见 [用户指南](../user-guide.md)，逐项需求证据见 [需求追踪矩阵](../records/requirements-traceability.md)。

## 下载内容

GitHub Release 提供：

- `RawViewer-v0.3.0-preview.2-windows-x64.zip`：完整便携包；
- `RawViewer-v0.3.0-preview.2-windows-x64.zip.sha256`：SHA-256 校验文件。

ZIP 内包含 `RawViewer.exe`、Qt 6.8.3 动态库、LibRaw 0.22.2、MSVC x64 Runtime、`qwindows` 平台插件、README、发布信息和第三方许可证。构建产物不提交到 Git 历史，统一作为 GitHub Release assets 保存。

## 安装与升级

无需安装。解压 ZIP 后运行 `RawViewer.exe`。从 Preview 1 升级时建议解压到新目录；最近文件记录保存在当前 Windows 用户设置中，可以继续使用。若需回滚，重新下载 Preview 1 并使用独立目录运行。
