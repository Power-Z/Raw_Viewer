# ADR-0002：不可变瓦片化图像管线

- 状态：提议
- 日期：2026-07-30
- 决策者：待用户确认
- 关联需求：DATA-004～DATA-006、PERF-001、TOOL-001～TOOL-004

## 背景

输入可能超过 2 亿像素、约 400 MB。需求要求保留原始数据、支持复杂 ISP、五步撤销、显示和统计。如果每个阶段保存完整图像，内存会快速增长到数 GB。

## 候选方案

### 方案 A：每步生成完整图像

- 优点：实现直观。
- 缺点：内存和延迟随处理步数线性增长。
- 风险：大图无法稳定工作，撤销成本不可接受。

### 方案 B：不可变源 + 操作描述 + 按需瓦片

- 优点：原始数据安全；只计算当前视口/统计需要的数据；撤销只切换管线版本。
- 缺点：缓存、边界 halo、任务取消和瓦片一致性更复杂。
- 风险：若缓存键或失效规则错误，可能显示旧结果。

## 决策

提议采用方案 B：

- 原始数据只读；
- 操作以可序列化参数描述；
- 中间结果按金字塔层级和瓦片惰性计算；
- 缓存有硬预算并使用 LRU；
- 后台任务带文档和管线世代号；
- 撤销栈只保存参数/管线快照，限制五步；
- CPU 实现是正确性基准，GPU 是可替换加速器。

## 后果

### 正面影响

- 峰值内存与可见工作集相关，而不是与整图和撤销步数直接相乘；
- 复杂 ISP 可以逐个操作扩展；
- 显示、导出和统计共享同一处理定义。

### 负面影响与债务

- 第一阶段必须提前定义端口和数据类型；
- 需要专门测试缓存失效、halo、取消和过期任务；
- 全图导出仍需要流式遍历全部瓦片。

## 验证与复审

第三阶段使用固定 200 MP / 400 MB 样本验证：

- 打开和首次预览耗时；
- 平移/缩放帧响应；
- 峰值工作集；
- 取消全图统计的响应时间；
- 参数改变后不存在旧瓦片闪回。
